# 🏥 Healthcare Medical Passport

An AI-Assisted Emergency Medical Information and Healthcare Resource Discovery platform designed to help users organize essential medical information, access AI-powered summaries and translations, and discover suitable healthcare resources during emergencies.

## 🚀 Features

* **Emergency Medical Passport:** Organize essential medical information in one place.
* **AI Summary & Translation:** Simplify medical information and support multilingual access.
* **Healthcare Resource Matching:** Discover suitable hospitals, diagnostic centres, beds, oxygen supplies, and other healthcare resources.
* **Controlled Emergency Access:** Enable authorized access to critical medical information for a limited time.
